# HEALIN GAMOGEN — Premium Wellness Animated Commercial (9:16)

An animated commercial for **HEALIN GAMOGEN** by House of Healin, built as an editable
**HyperFrames** composition (HTML + GSAP) and mixed and mastered with **FFmpeg**.

| | |
|---|---|
| Final video | `output/HEALIN_GAMOGEN_Commercial_9x16_1080x1920.mp4` |
| Format | 1080 × 1920 (9:16), 30 fps, H.264 High / yuv420p, AAC 48 kHz stereo, −14 LUFS |
| Length | 107.5 s: the full 102.0 s original narration plus a 5.8 s CTA end card |
| Subtitles (separate file) | `output/HEALIN_GAMOGEN_subtitles_ms.srt` (they are also burned into the video) |

## Pipeline

```
audio/source/original_voiceover.mp4 ──► scripts/extract_audio.sh ──► voiceover.wav (lossless, untouched)
                                         scripts/transcribe.py (faster-whisper, word timestamps)
                                         └► project/transcript_raw_medium.json → corrected cues in components/subtitles.js
assets/product-images/gamogen_official.jpg ─► scripts/cutout_product.py ─► bottle.png / product_full.png
                                                (alpha only; label pixels are never edited)
scripts/make_audio.py ──► original music bed + SFX (procedurally synthesised, royalty-free)
index.html + components/ + scenes/ ──► npx hyperframes render ──► output/_video_silent.mp4
scripts/check_page.cjs ──► project/sfx_cues.json (SFX cue sheet read from the animation timeline)
scripts/build_sfx_track.py ─► scripts/mix_audio.sh (side-chain ducking + 2-pass loudnorm) ─► scripts/master.sh ─► scripts/qc.sh
```

To rebuild everything, run `npm install`, then `./scripts/render.sh`. To re-mix the audio without
re-rendering the video, run `SKIP_VIDEO=1 ./scripts/render.sh`.
To preview or edit the animation in HyperFrames Studio, run `npx hyperframes preview`.

## Folder structure

| Folder | Contents |
|---|---|
| `index.html` | Main HyperFrames composition: scene windows, overlays and the master timeline |
| `scenes/` | One file per scene (`s01-opening.js` … `s08-closing.js`). Tweens are placed at absolute narration times |
| `components/` | Reusable animation components: `core` (palette, PRNG, SFX registry), `kinetic` (typography), `fx` (particles, light sweeps, product hero, pedestal, arches), `illustrations` (SVG art), `figures` (rigged adult characters), `icons`, `subtitles`, plus `vendor/gsap` |
| `assets/product-images/` | The supplied product photo and logo, plus the cut-outs made from them |
| `assets/fonts/` | Montserrat, Plus Jakarta Sans, DM Sans and Playfair Display (OFL, self-hosted) |
| `audio/` | `source/` (the original MP4), `music/` (bed), `sfx/` (individual effects), `mix/` (stems and final mix, regenerated by the scripts) |
| `scripts/` | Python, Node and FFmpeg scripts used in production |
| `project/` | Transcripts, the SFX cue sheet and review snapshots |
| `output/` | Final deliverables |

## Compliance notes

- The original Malay voice-over is used as it is. It is not cut, sped up, regenerated or replaced; the CTA end card is added after the narration ends.
- The product photo is only cut out. The label, bottle shape and colours are not altered.
- No numbers, percentages or sample sizes appear anywhere. Charts are abstract and labelled as illustrations, and the animal-model status is stated on screen.
- No USM logo or endorsement is implied; the institution drawing is generic.
- Traditional use is labelled as heritage, not clinical evidence.
- The supplement is shown as one of four equal lifestyle pillars, never as a replacement.
- No contact numbers, websites or social handles were invented.
